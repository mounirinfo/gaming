🎮 How to Play Minesweeper Mobile (Expo Go)

This guide will help you get the game running on your Android or iOS device in minutes.

1. Prerequisites (Do this first)

Before you start, make sure you have these two things:

Computer: Install Node.js (LTS version).

Phone: Download the Expo Go app from your app store.

🤖 Expo Go for Android

🍎 Expo Go for iOS

2. Setup the Game

Open your terminal (Command Prompt, PowerShell, or Terminal) and navigate to the project folder.

Install Dependencies:
Run this command to download the necessary libraries:

npm install


(This might take a minute or two)

3. Run the App

Start the Server:
Run this command in your terminal:

npx expo start


Scan the QR Code:

Android: Open the Expo Go app and tap "Scan QR Code". Scan the QR code shown in your terminal.

iOS: Open your standard Camera App, point it at the QR code, and tap the notification to open in Expo Go.

Note: If the QR code doesn't appear, press c in the terminal to clear/show it again.

4. How to Play 🕹️

Once the app loads on your phone, here are the controls:

💣 Dig Mode: Tap a square to reveal it.

🚩 Flag Mode:

Option A: Use the toggle button at the bottom to switch to "FLAG" mode, then tap squares.

Option B: Long-press (hold down) on a square to flag it quickly without switching modes.

⚡ Chording (Pro Move):
If a number (e.g., "1") is already revealed and has the correct number of flags touching it, tap the number itself to instantly reveal all other neighbors.

Themes:

Tap the 🌙/☀️ icon in the top right to toggle Dark Mode.

Difficulty:

Tap the Settings (gear icon) to restart or change difficulty (Easy, Medium, Hard).
